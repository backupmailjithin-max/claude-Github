# PDU Backup Coverage Closure (F8)
Date: 2026-10-22 · Version 3.2.2 · Approved by the project owner in the 2026-10-22 brief.
Scope: Backup / Restore / Rollback only. No change to inventory, lifecycle, OCR, monitoring, OME, OneView, compliance, transfers, store, reports or any API.

## 1. Impact analysis
- The `pdus` table (PDU definitions, SNMP configuration and monitoring mappings: IP, vendor/model/serial, rack and feed, phase, max load, SNMP community, power OID, scale, poll interval, status) is now part of every backup and restore.
- Not included, on purpose: `power_readings` (daily power history, regenerated by polling) and `audit_logs`. After a restore onto an empty database the PDU list is back and trends rebuild from the next polls.
- The restore deletes rows with foreign-key checks off, so existing power history is not cascade-deleted by a restore (tested). History of PDUs deleted through the app is lost, as before.
- The backup file now carries each PDU's SNMP community string in plain text, like the rest of the data. Backups are Global-Admin only.
- Installer rollback (Linux and Windows) already restores the complete database dump, so PDUs were covered there; verified the dump carries the `pdus` rows.

## 2. Backup format impact
- Format name and version unchanged (`version: 1`). One additional table key, `pdus`, and one additional entry in `counts`.
- Forward note: an older application version refuses a new backup ("unknown table pdus"). Restore a new backup with the new version.

## 3. Migration strategy
- None needed. Old backups have no `pdus` key; restore reports it as untouched and leaves the current PDU list alone (never wipes it).
- Install without a `pdus` table (module not yet initialised): the table is left out of the backup and skipped on restore, instead of failing or writing an empty list.

## 4. Updated files
- `dcim/webapp/server.js` – `pdus` added to the backup table list; optional-table guards in backup, count and restore.
- `dcim/webapp/app-compiled.js` and `app-compiled.min.js` – one label ("PDUs") in the restore preview.
