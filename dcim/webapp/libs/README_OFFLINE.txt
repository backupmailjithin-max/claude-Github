DCIM Dashboard Offline Libraries

Included fonts:
- Inter Regular
- Inter Medium
- Inter SemiBold
- Inter Bold

Run download-libs.bat once on a Windows PC with internet access.
It downloads the exact JavaScript runtime/export libraries required by index.html:
- React 18
- ReactDOM 18
- Babel Standalone 7
- SheetJS XLSX 0.20.1
- ExcelJS 4.4.0
- html2canvas 1.4.1

After the downloads finish, the complete dashboard package can be moved to an offline PC.
