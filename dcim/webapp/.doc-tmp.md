# Asset form: Rack no. list after choosing a Rack type (2026-11-18)

Problem: in Asset Inventory > Edit asset, choosing a Rack type did not always offer that type's racks (plain text box instead of a list).

Fix (app-compiled.js, NewAssetModal): Rack no. lists the racks of the chosen Rack type in the SELECTED Site + Zone only. Rack type, rack no. and zone are now matched ignoring case, spaces, hyphens and underscores (COMP-1 = Comp 1 = comp1), so differently written type names no longer hide racks. When the selected zone has no rack of that type, a note says where such racks exist ("Found in AZ-2 - change Zone to pick one") or that none exist in the site (type a new rack no.).

Validation: browser tests on the edit form (Network -> B02; Storage -> C01 (AZ-2 rack C09 not shown); COMP-1 -> A04, A05 incl. "Comp 1" spelled rack; COMP-2 -> hint pointing to AZ-2; BACKUP -> new-rack hint). API suites 255/255, unit tests 63/63, UI sweep 138 views x 3 sizes x 3 roles: 0 problems. Rack Component form still has a plain Rack no. box (unchanged).
